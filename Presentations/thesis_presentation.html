📄 Phase 1: Extract (PDF → Text)

  • Tool: PyPDF2 or pdfplumber for PDF parsing
  • Process: Extract text, preserve section structure
  • Metadata: Capture page numbers, section headers, hierarchy
  • Output: Structured text with source references (e.g., "BSI-200-1, Section 3.2.2")
  • Challenge: Handle PDFs with varying layouts and quality
9 / 31

🔄 Phase 2: Transform (NLP Classification)

  • Method: TF-IDF vectorization + cosine similarity
  • Input: Text segments from extracted PDFs
  • Process: Compare text against lifecycle phase descriptions
  • Output: Assigned lifecycle phase (Plan, Do, Check, Act) or (Identify, Protect, Detect, Respond, Recover)
  • Benefit: Automatic classification without manual tagging
10 / 31

💾 Phase 3: Load (JSON → PostgreSQL)

  • Format: JSON intermediate representation
  • Schema: Normalized relational tables (standards, requirements, lifecycle_phases, mappings)
  • Relationships: Foreign keys for cross-standard linkage
  • Metadata: Source nodes, DOC flags, security levels, zones
  • Outcome: Queryable, analyzable security knowledge base

🧠 Technical Deep Dive: NLP Classification

vectorizer = TfidfVectorizer() phase_names = ["Plan", "Do", "Check", "Act"] phase_texts = [ "Identify framework conditions, define objectives...", "Implement security concept and measures...", "Review and monitor effectiveness...", "Correct weaknesses and improve..." ] phase_vectors = vectorizer.fit_transform(phase_texts) def extract_lifecycle(text): text_vector = vectorizer.transform([text]) similarities = cosine_similarity(text_vector, phase_vectors)[0] best_match = phase_names[similarities.argmax()] return best_match

🔍 Query Examples from PostgreSQL

-- Find all Check-phase requirements from BSI SELECT r.text, r.source_node FROM requirements r JOIN lifecycle_phases lp ON r.id = lp.requirement_id WHERE r.standard_id = 'BSI-200-1' AND lp.phase_name = 'Check'; -- Map NIST Detect to BSI Check SELECT m.source_req_id, m.target_req_id, m.alignment_score FROM mappings m WHERE m.source_phase = 'Detect' AND m.target_phase = 'Check';

⚠️ Limitations & Challenges

  • TF-IDF Limitation: Lexical overlap only; may miss semantic meaning with different phrasing
  • PDF Quality: Some standards have complex layouts that extract imperfectly
  • Manual Validation: Cross-standard mappings partially rely on expert judgment
  • Scalability: Performance with 1000+ standards not yet tested
